「偏好设置」页集中管理应用的全局配置，页面自上而下分为：顶部的「帮助与教程」渐变入口卡、「设备」信息卡，以及三组圆角分组列表（外观与偏好、目录与服务、关于）。大部分改动即时保存并立即生效。

## 帮助与教程

页面顶部的紫色渐变卡片就是应用内教程的入口，点击进入「帮助与教程」页（即你正在看的这份双语指南）：先看到全部章节的列表，点任意章节即可阅读。文档内容在线更新，无需等待应用发版。

## 设备

入口卡下方的「设备」卡汇总本机关键信息：操作系统、CPU 架构（如 `arm64` / `amd64`）、llama-server 推理构建（CUDA / Vulkan / Metal / CPU，安卓为 CPU 构建）与当前应用版本，桌面端和移动端都会显示。

## 外观与偏好

- **主题模式**：深色 / 浅色一键切换（渐变胶囊开关）；
- **界面语言**：自动（跟随系统）、中文、English 三选一，切换即时生效（教程内容的语言也跟随这里）；
- **模型下载源**：三个可选源：**HF 镜像**（hf-mirror.com）、**ModelScope**（魔搭）、**Hugging Face 官方**（huggingface.co）。该设置同时作用于「模型管理」页「下载模型」标签的搜索和下载，国内网络推荐镜像或魔搭。

## 目录与服务

**下载路径**：

- **llama.cpp 下载路径**：新下载的 llama.cpp 安装到哪里；
- **模型下载路径**：新下载的模型保存到哪里（默认是应用目录下的 `LLM-Models`）。

这两个路径决定**新内容**的落点；想复用电脑里已有的模型文件，去「模型管理」页「我的模型」标签用「选择文件夹」设置外部路径。Android 上这些路径由应用管理，仅供查看。

**服务访问范围**：`本地（127.0.0.1）` 仅本机可访问；`局域网（0.0.0.0）` 允许同网络设备访问。修改后在下一次启动服务时生效。

**API Key**：可选的 Bearer Token。设置后所有推理接口请求都需要携带它，留空表示不认证。即使只在本地使用，设置 API Key 也能防止本机其他程序随意调用。密钥在服务**下一次启动**时生效——保存时若服务正在运行，应用会询问是否立即重启。

**局域网连接**：服务访问范围为「局域网」时，该卡片显示绿点「已就绪」状态，列出本机在局域网中的地址、服务端口与 API Key 状态，每项一键复制；桌面端还会在白底卡片里渲染**配对二维码**（含地址、端口与 API Key 的 `myllama://pair` 链接），手机 MyLlama 扫一扫即可整包导入。多个局域网地址时可用小选择器切换二维码对应的地址，「刷新二维码」换下一个地址重新渲染，「复制链接」把整包链接复制到剪贴板。本机未设置 API Key 时状态行会建议先设置（对方仍可免密连接）。**二维码含本机服务地址与 API Key，请勿展示给不可信对象。** 服务访问范围为「本地」时，卡片展示切换为局域网的引导（沿用上方「服务访问范围」这一处开关）。

**远程聊天**：反向配对——让本应用（如手机）连接同一局域网内另一台电脑的 llama-server：Android 端点「**扫码导入**」对准电脑端「局域网连接」卡的二维码即可自动填入电脑地址、端口与 API Key（首次使用需授权相机）；所有平台都可点「**从剪贴板导入**」粘贴电脑端复制过的 `myllama://pair` 链接，或手动填写电脑地址（仅主机名或 IP）、端口与对方设置的 API Key。导入只填表不保存，核对无误后打开开关并保存，然后在聊天页把「对话目标」切换为「远程 PC」。局域网为明文传输，API Key 用于防止蹭网，不能防窃听；详细步骤见「本地聊天」章节的「局域网远程对话」。

**推理显卡**：多显卡机器上选择 llama-server 使用哪张 NVIDIA 显卡（按稳定 UUID 记录，通过 `CUDA_VISIBLE_DEVICES` 传给服务进程）。没有 NVIDIA 显卡时此项不可选，服务使用默认设备。「一键调优」也会按这里所选的显卡规划显存。仅 Windows 显示此项。

**系统托盘（Windows / macOS）**：开启后，点击关闭按钮会把窗口最小化到系统托盘，llama-server 继续在后台运行；从托盘图标菜单可以重新打开主窗口或退出应用。该设置项按平台可用性显示（Linux 桌面环境的托盘支持不完整，暂不提供）。注意：关闭托盘后想再次启用，需要重启应用才能生效。

**API 路由模式**：把应用切换成纯后台服务模式（无界面，仅托盘 + 服务），详见「无头模式」章节。仅 Windows 可用，且需要先开启系统托盘。

## 关于

- **更新**：应用每两天自动检查一次新版本，发现新版本会弹出应用内更新提示。设置页「更新」行在 Android 同样提供「检查更新」按钮（下载的 APK 经系统安装器确认安装，首次需授予"安装未知应用"权限）；GitHub Releases 链接作为辅助入口保留。Windows 的「检查更新」走 NSIS 安装器自更新。Linux / macOS 无内置更新通道，只显示前往 GitHub Releases 的链接。
- **版本 / 开源协议 / 项目仓库**：当前版本号、GPL-3.0 协议与仓库地址。手机端这三项合并为一行「关于」，点按即可打开仓库页面。
