「模型管理」页顶部用分段控件在「下载模型」与「我的模型」两个标签间切换；「下载模型」标签从在线模型仓库搜索并下载 `.gguf` 模型文件。已下载和已导入的模型统一显示在「我的模型」标签。

## 三个下载源

应用支持三个模型源，在「偏好设置」页的「模型下载源」行中切换，该设置同时作用于搜索和下载：

| 源 | 说明 |
| --- | --- |
| HF 镜像 | hf-mirror.com 的镜像，国内网络首选，速度稳定 |
| ModelScope | 魔搭社区，阿里云托管，国内模型收录齐全 |
| Hugging Face 官方 | huggingface.co，模型最全，海外网络使用 |

## 搜索与下载

1. 在胶囊形搜索框输入模型名或关键词，回车或点「搜索」。
2. 点击结果卡片进入**模型详情**页：
   - **文件列表**：列出仓库中的全部文件，按大小排序并猜测量化等级；勾选你要的 `.gguf` 文件（多模态模型还要勾选 `mmproj` 视觉文件），点「下载选中文件」；`mmproj` 视觉文件带 👁️ 多模态徽标，仓库里有它而你还没勾选时，下载栏上方会提示一并勾选——视觉模型缺了它就无法看图；
   - **模型说明**：展示仓库的 README 描述，帮助判断模型能力。
3. 下载任务立即开始，进度实时更新——进行中的下载会以进度卡形式置顶显示在页面上方，点它也能打开下载管理面板。

## 下载任务管理

点搜索框旁的「下载」胶囊按钮打开下载管理面板，分两个标签：

- **下载任务**：进行中和排队的任务，可暂停、继续、重试、取消；
- **下载历史**：已完成、失败、取消的任务记录。

下载支持**断点续传**：暂停或失败后继续时，从已下载的部分接着传。网络抖动会自动重试（最多 3 次）。全局任务卡也会实时显示下载进度，任何页面都能看到。任务卡默认贴右下角，可拖动并吸附到左 / 右边缘。

## 外部导入：复用已有的模型

如果你电脑上已经有 GGUF 文件，不必重新下载：

1. 打开「模型管理」页的「我的模型」标签，点「选择文件夹」；
2. 选择存放模型的目录，应用会立即扫描并把里面的模型加入列表。

「我的模型」标签会把**下载路径**和**外部路径**的模型合并展示，每个模型带来源标注（下载路径 / 外部路径）。外部路径会连同子目录一起扫描，结果显示模型的架构、量化和体积。
