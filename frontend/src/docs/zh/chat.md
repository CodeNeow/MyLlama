「本地聊天」页提供一个开箱即用的对话界面，直接与本地模型对话，数据不出本机。

## 开始对话

1. 在顶部的模型胶囊中选择要对话的模型（点开即弹出本机已识别的模型列表，无需先启动服务）;
2. 在底部悬浮输入条输入消息，**Enter 发送，Shift+Enter 换行**，或点右侧的圆形渐变发送钮；
3. 发送时若服务尚未启动，应用会**自动拉起本地服务**并按需加载所选模型，然后开始流式输出——无需手动去「API 路由」页启动（该页仍可手动启停与监控）；
4. 回复以流式方式逐字输出，生成中发送钮会变成红色停止钮，点击可随时中断；结束后显示本条消息的生成速度（tok/s）。

自动启动前会先做引导检查：没有可用模型时提示去「模型管理」页下载或导入；llama.cpp 运行时未安装时提示去「本机环境」页的「运行环境」标签下载，按提示补齐后即可直接开聊。

发送消息时会先自动卸载其他已加载的模型，保证内存中只保留当前选中的模型；模型的加载 / 卸载变化会实时反映在任务卡片中，也可以随时在那里手动卸载释放资源。任务卡默认贴窗口右下角，可拖动并吸附到左 / 右边缘。

> Android 平台说明：官方 Android 版 llama-server 以**直连模式**运行——一个服务进程只驻留一个模型。发送时若所选模型不是当前驻留模型，应用会自动重启服务以加载新模型（首次启动耗时也更长，请耐心等待）；任务卡片与主页「常驻模型」卡均提供卸载按钮——直连模式下卸载即停止服务、随之释放内存，下次发送消息时会自动重启服务。桌面平台仍为路由模式，支持多模型按需加载与卸载，行为不变。

支持多模态的模型（带 mmproj 文件）可以点输入条旁的附件按钮添加图片，让模型看图说话。

视觉模型需要**两个文件**：主权重 `.gguf` 和 `mmproj` 视觉投影器 `.gguf`。若当前选中的模型缺少投影文件（同目录没有 mmproj 文件，模型设置里也没有手动指定投影路径），聊天页会禁用附件按钮；粘贴或选择图片会被拦下并提示；带图发送时也会被兜底拦下，并给出补文件指引——到「模型管理 → 下载模型」重新进入模型详情页，勾选带 👁️ 多模态徽标的 mmproj 文件补下即可，或在「模型设置」中手动指定投影路径。

## 局域网远程对话（手机连电脑）

聊天页顶部的「对话目标」切换器可在 **本机服务** 与 **远程 PC** 之间切换；该切换器在配置远程电脑后才会出现（设置 → 局域网互联 → 连接其他电脑）。远程档下，聊天请求直接发往同一局域网内另一台电脑正在运行的 llama-server：模型列表、卸载其他模型与流式对话全部作用于那台电脑，本机无需安装任何模型或运行时。

**电脑端（服务方）三步**（详见「偏好设置」章节）：

1. 在「设置 → 服务访问范围」把服务切换为**局域网（0.0.0.0）**（修改在下一次启动服务时生效）；
2. 在「设置 → API Key」设置一个密钥（强烈建议：局域网内任何设备都能扫到服务端口）；
3. 打开「设置 → 局域网互联 → 共享本机服务」：桌面端会显示**配对二维码**（含本机地址、端口与 API Key），用另一台 MyLlama 扫一扫即可整包导入；也可以点「复制链接」后让对方从剪贴板导入，或逐项复制地址、端口与密钥手动填写。

**手机端（对话方）三步**：

1. 在「设置 → 局域网互联 → 连接其他电脑」点「**扫码导入**」（Android），对准电脑上的配对二维码即可自动填入电脑地址、端口与 API Key——首次使用会请求**相机权限**，一次授权后不再重复询问；没有相机或在电脑上操作时，点「**从剪贴板导入**」粘贴电脑端复制的 `myllama://pair` 链接，或手动填写电脑地址（仅主机名或 IP，如 `192.168.1.5`）、端口与电脑端设置的 API Key；
2. 核对导入的字段无误后，打开**启用远程聊天**开关并保存（导入只填表，不会自动保存）；
3. 回到聊天页，把「对话目标」切换为**远程 PC**——模型列表会变为电脑上的模型，直接发送即可流式对话。

远程档下电脑端服务由电脑自己管理：聊天页不会自动启动或停止它，仅在连接失败时提示检查地址、端口与防火墙。「本机服务」档的所有行为保持不变。

连不上电脑时，工具栏下方会出现一条琥珀色警示（列出可能原因：地址 / 端口不对、对方电脑的服务未运行、对方防火墙未放行该端口），并附「重试」按钮，点击即可重新探测；若电脑在线但尚未加载任何模型，则会显示一条灰色提示——在对方电脑的聊天页选一个模型发送一条消息（服务端会懒加载该模型），它就会出现在本机的模型列表里。

> 安全边界：局域网传输为**明文 HTTP**，API Key 只能防止无关设备蹭用服务，**不能防止同一网络内的窃听**；请仅在可信网络中启用远程聊天。

## 调整对话参数

采样参数由顶部工具栏、模型胶囊旁的**采样预设**控制，借鉴 unsloth 的生成预设：**默认**（不覆盖，走模型设置里为每个模型保存的服务端采样参数）、**精确**（temperature 0.3 / top_p 0.8 / top_k 20 / repeat_penalty 1.1）、**均衡**（0.7 / 0.9 / 40 / 1.1）、**创意**（1.0 / 0.95 / 60 / 1.05）与**随机**（1.2 / 1.0 / 80 / 1.0）。选中非「默认」预设时，发送的请求体会附带这四个采样覆盖字段；选「默认」则不带，由服务端参数决定。选中的预设会记住，下次打开聊天继续生效。

选中一个非「默认」预设后，可点工具栏的书签图标打开「管理预设」：把当前预设**另存为**自定义命名预设（最多 20 个），也可在列表中删除不需要的自定义预设。

点顶部工具栏右侧的齿轮图标展开参数面板，可调整：

- **采样预设摘要**：面板顶部只读展示当前预设及其四个采样值；
- **最大生成 Token**：单次回复的长度上限；
- **系统提示词**：给模型的人设或任务说明，留空则不注入。

点「恢复默认」可还原最大 Token 与系统提示词。参数改动即时生效于下一次请求。

## 思考过程

推理类模型（如 DeepSeek-R1 系列）输出思考过程时，聊天页会把它折叠进「思考过程」块，点击可展开查看，正文只显示最终回答——两种内容分开统计速度。

## 对话记录

- 点「清空对话」删除当前会话；
- 对话记录保存在本机（浏览器本地存储），关闭应用后再次打开可以继续上一次对话。

聊天页发送的每一轮请求都走本地服务，不会上传任何数据到云端。
